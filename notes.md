# Lab Notebook

A running log of experiments, observations, and ideas worth keeping.

## Quick Start

1. Clone the repo.
2. Run `pnpm install`.
3. Open `notes.md` in your editor and add your first entry.

## Usage

Open `notes.md` and start writing. Save often — commits are cheap.

## Entry Tips

- Log a hypothesis before running the experiment.
- Record unexpected results verbatim.
- Link related entries by date.

## Installation

Requires Node.js 18+ and pnpm 9+.

Clone the repo and run `pnpm install`.
