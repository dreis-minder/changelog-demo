# Lab Notebook

A running log of experiments, observations, and ideas worth keeping.

## Quick Start

1. Clone the repo.
2. Run `pnpm install`.
3. Open `notes.md` and add your first entry.

## Usage

Open `notes.md` and start writing. Save often.

## Examples

- Log a hypothesis before the experiment.
- Record unexpected results verbatim.
- Link related entries by date.

## Installation

Clone the repo and run `pnpm install`.
